## 二、等你在浏览器里确认（重要）

这轮有三个 bug 是**只有在浏览器里点才会暴露**的（按钮不渲染、请求体多带字段、闭包拿到过期 id）。开发环境没有浏览器工具，接口和构建产物能验，**交互验不了**。以下几条还没有人实际点过：

- [ ] 新建 → 输入 → 保存：不弹「还有未保存的修改」，自动回到列表并显示绿色提示
- [ ] 新建 → 直接加照片：只生成 **1 条私密草稿**，不出现在前台
- [ ] 连续上传多张照片：顺序正确，已填的照片说明不被覆盖
- [ ] 照片墙滚动框在手机上会不会太矮（现在封顶 47vh）
- [ ] 正文框 10 行起是否合适（改 `Admin.tsx` 里 `autoSize` 的 `minRows`）
- [ ] 「AI 帮我写」弹窗能正常打开（成员账号也要试，之前只有管理员能开）

发现问题时，**把浏览器 Network 面板里的请求体截图发出来最有用**，比任何文字描述都快。
